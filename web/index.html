01

Touchpad Lock

Press ⌃⌥⌘T to freeze only the trackpad. Clicks, taps, and gestures are completely blocked while your keyboard stays functional.

02

Full Keyboard Lock

Press ⌃⌥⌘K to lock down both the keyboard and touchpad simultaneously. Wipe across keycaps and surface safely.

03

Fail-Safe Recovery

Never get locked out. Re-pressing the shortcut or using the emergency key sequence instantly restores all inputs.

04

Stealth & Native

Runs silently as a native macOS menu bar app. Zero CPU overhead, no battery drain, and optional hidden icon mode.
